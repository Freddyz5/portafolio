## 🎯 Acerca de Este Proyecto

Este es mi portafolio profesional personal, una aplicación web moderna y altamente interactiva que muestra mi experiencia, habilidades y proyectos destacados. Diseñado con un enfoque en la experiencia de usuario y el rendimiento, este sitio refleja mi capacidad para crear aplicaciones web profesionales de alta calidad.

### ✨ Características Destacadas

- 🌐 **Multiidioma**: Soporte completo para español e inglés
- 📱 **Diseño Responsivo**: Experiencia óptima en todos los dispositivos
- ⚡ **Alto Rendimiento**: Construido con Astro para máxima velocidad
- 🎨 **Animaciones Fluidas**: Interfaz interactiva con Anime.js
- 📄 **CV Interactivo**: Currículum vitae navegable y descargable
- 🎮 **Atajos de Teclado**: Navegación avanzada con hotkeys
- 🔧 **Panel de Configuración**: Sistema JSON editable en tiempo real
- 🚀 **CI/CD Automatizado**: Despliegue continuo con GitHub Actions

## 🏗️ Arquitectura del Proyecto

```
portafolio/
├── 📁 src/
│   ├── 📁 modules/          # Módulos principales de la aplicación
│   │   ├── 📁 portfolio/    # Sección de portafolio
│   │   ├── 📁 cv/           # Currículum vitae interactivo
│   │   └── 📁 configurations/ # Panel de administración JSON
│   ├── 📁 pages/            # Rutas y páginas de Astro
│   ├── 📁 shared/           # Componentes e íconos compartidos
│   └── 📄 resume.json       # Datos centralizados del CV
├── 📁 public/               # Recursos estáticos
└── 📄 astro.config.mjs      # Configuración de Astro
```

### Módulos Principales

#### 🎨 **Portfolio**
Showcase interactivo de proyectos con:
- Cards de proyectos con efectos glitch
- Páginas de detalle de proyectos
- Sección de experiencia laboral
- Formulario de contacto con efectos personalizados

#### 📄 **Curriculum Vitae**
CV interactivo con:
- Navegación por secciones con atajos de teclado
- Diseño profesional optimizado para impresión
- Información multiidioma sincronizada
- Secciones: Experiencia, Educación, Habilidades, Idiomas

#### ⚙️ **Panel de Configuraciones**
Sistema de administración que permite:
- Editar el archivo `resume.json` en tiempo real
- Visualización de árbol JSON navegable
- Agregar/editar/eliminar nodos
- Sincronización automática con el sitio
